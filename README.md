# MachoHQ — Your Operating System

Personal operating system for NeoLife network marketing, freelancing, and growth.

## Features

**8 tabs:**
- **HQ** — Morning War Room with Director Challenge countdown, daily power actions, Macho Score
- **NeoLife** — Team tree, PV tracker, status progression (Newbie → Pro → Distributor), 5-step Add Downline flow
- **Pipeline** — 8-stage prospect pipeline (Cold List → Joined) with relationship decay tracking
- **Focus** — Timer with 4 blocks, countdown ring, end-of-block check-in with distraction tracking
- **Fiverr** — Account management for 20+ accounts, gig tracking with health scores, AI gig audit
- **Growth** — Earnings tracker (auto Fiverr/Upwork fee deduction, naira conversion) + Book reading system (15 pages/day target)
- **Score** — Macho Score with 8-category breakdown, achievements, punishment system, weekly chart
- **AI** — Claude-powered adviser with 56-book knowledge base, prospect simulator, team training generator

**Other screens:**
- Lock screen with PIN
- No Excuses Journal
- Weekly Review with WhatsApp sharing
- Spending tracker with 10 categories and budgets

**AI Knowledge Base:**
56 books including Go Pro (Eric Worre), Psychology of Selling (Brian Tracy), 21 Irrefutable Laws of Leadership (John Maxwell), and more. AI adviser draws from this knowledge when answering questions.

## Tech Stack

- Expo / React Native
- React Navigation (bottom tabs)
- AsyncStorage for persistence
- Claude API for AI features
- Offline-first architecture

## Build

```bash
npm install
npx expo start
```
